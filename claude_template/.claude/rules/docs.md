# Markdown and docs

- Edit the section that changes; never rewrite a document over 100 lines unless more than
  30% of it changes.
- Before editing, `Grep -n '^#'` to find the section, then `Read` that range only.
- Keep the file's existing heading structure; do not add summaries that restate content.
- A doc's change is verified by re-reading only the edited range, not the whole file.
